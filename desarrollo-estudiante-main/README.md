## Descripción

Este proyecto propone una secuencia de prompts donde el alumno desarrolle una landing page de manera progresiva.  
Cada paso genera un entregable concreto y facilita la revisión, la corrección y la integración final del proyecto.

## Objetivo

Construir una landing page completa aplicando buenas prácticas de desarrollo web, estructura semántica, diseño responsive, interacción básica y preparación para despliegue.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
- Diseño responsivo
- Desarrollo frontend

## Estructura del proceso

1. Definir el objetivo de la landing.
2. Crear el contenido base.
3. Diseñar la estructura HTML.
4. Diseñar el CSS base.
5. Agregar responsividad.
6. Agregar interacción con JavaScript.
7. Conectar formulario de contacto.
8. Mejorar accesibilidad y SEO.
9. Revisar y optimizar.
10. Preparar despliegue.

## Prompts sugeridos

### 1. Definir el objetivo
```text
Actúa como especialista en UX y copywriting. Ayúdame a definir el objetivo de una landing page para [tema del proyecto]. Dame: público objetivo, propuesta de valor, llamada a la acción principal, secciones necesarias y tono de comunicación.
```

### 2. Crear el contenido base
```text
Ahora redacta el contenido completo de la landing page con estas secciones: encabezado, hero, beneficios, características, testimonios, FAQ y contacto. Escribe textos claros, cortos y persuasivos en español.
```

### 3. Diseñar la estructura HTML
```text
Genera solo la estructura HTML semántica de la landing page usando header, main, section, article, footer y botones. No incluyas estilos ni JavaScript. Usa clases claras y ordenadas.
```

### 4. Diseñar el CSS base
```text
Crea el archivo CSS para esta landing page. Debe ser moderna, responsiva, visualmente atractiva y fácil de leer. Usa colores, espaciado, tipografía, tarjetas, botones y diseño adaptable para móvil, tablet y escritorio.
```

### 5. Agregar responsividad
```text
Optimiza el CSS anterior para que la landing page se vea bien en pantallas pequeñas, medianas y grandes. Usa media queries, grids o flexbox donde sea necesario.
```

### 6. Agregar interacción con JavaScript
```text
Genera JavaScript para mejorar la landing page con estas funciones: menú móvil, scroll suave, validación básica de formulario y efectos simples de interacción. Mantén el código limpio y comentado.
```

### 7. Conectar formulario de contacto
```text
Crea la lógica para validar y simular el envío del formulario de contacto de la landing page. Si no hay backend, muestra un mensaje de confirmación visual sin recargar la página.
```

### 8. Mejorar accesibilidad y SEO
```text
Revisa esta landing page y propón mejoras de accesibilidad y SEO. Incluye recomendaciones sobre títulos, etiquetas alt, contraste, orden semántico, meta etiquetas y botones accesibles.
```

### 9. Revisar y optimizar
```text
Analiza el código completo de la landing page y optimízalo. Corrige errores, mejora la estructura, reduce redundancias y sugiere mejores prácticas de desarrollo frontend.
```

### 10. Preparar despliegue
```text
Explícame cómo preparar esta landing page para publicarla. Incluye estructura de carpetas, archivos necesarios y una opción simple de despliegue con GitHub Pages o servidor estático.
```

## Flujo recomendado

El estudiante debe avanzar en orden, sin saltarse pasos. Primero define el objetivo y el contenido, luego construye la estructura, después aplica estilos, incorpora interacciones y finalmente revisa accesibilidad y despliegue.
